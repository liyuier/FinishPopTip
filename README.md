# 核心功能
按下 S 键可一键终止未弹完的提示条弹窗继续弹出，避免特定情况下，大量提示条弹窗长时间遮挡画面 UI.

# 补充说明
- 仅会清除按下快捷键之前产生而未弹完的弹窗；如果按下快捷键后，又产生新的弹窗，MOD 不会阻止其弹出。
- 安装 [【插件配置】BepInEx插件管理器](https://steamcommunity.com/sharedfiles/filedetails/?id=2825202474) MOD 后，可在游戏内按 F1 打开配置管理界面修改快捷键。
